# Banco de Dados Não Relacional

Este repositório reúne materiais de apoio, exemplos práticos e exercícios utilizados na disciplina de Banco de Dados Não Relacional.

O objetivo da disciplina é apresentar conceitos, técnicas e práticas relacionados ao uso de bancos de dados NoSQL, com foco na compreensão de diferentes modelos de dados, critérios de modelagem, comandos de manipulação e estratégias para organização de informações em cenários reais.

Ao longo dos estudos, os alunos terão contato com temas como:

- fundamentos de bancos de dados não relacionais;
- diferenças entre bancos relacionais e NoSQL;
- modelagem orientada a documentos;
- documentos embutidos e referências;
- comandos de consulta e manipulação de dados;
- integridade, consistência e automação em ambientes NoSQL;
- boas práticas para estruturação de dados conforme o contexto da aplicação.

Os arquivos estão organizados por aulas e podem incluir textos explicativos, exemplos de código e atividades práticas. A proposta é que o repositório funcione como material complementar para estudo, consulta e acompanhamento das atividades desenvolvidas em sala.

## Como utilizar este material

Recomenda-se acompanhar os arquivos na ordem indicada pelos nomes das pastas e dos materiais. Os exemplos podem ser executados, adaptados e expandidos durante as aulas ou em atividades individuais.

Sempre que possível, leia primeiro o material teórico, depois analise os exemplos e, por fim, resolva os exercícios propostos. Essa sequência ajuda a consolidar os conceitos antes da aplicação prática.
