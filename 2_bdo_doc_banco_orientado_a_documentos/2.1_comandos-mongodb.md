# 2.1 Comandos MongoDB: exemplos progressivos e exercícios

Este material entra antes dos exemplos de integridade e automação. A ideia é praticar os comandos essenciais do MongoDB aos poucos, com exemplos pequenos, até chegar em situações mais próximas de um projeto real.

Os comandos abaixo podem ser executados no `mongosh`.

---

## 1. Criando e selecionando um banco

```javascript
use biblioteca
```

No MongoDB, o banco só passa a existir de fato quando recebe dados.

```javascript
db
```

Listar bancos:

```javascript
show dbs
```

Listar coleções do banco atual:

```javascript
show collections
```

```javascript

  autor: "Machado de Assis",
```

## 5. Projeção: escolhendo campos exibidos


```javascript
db.livros.find(
```

## 6. Operadores de comparação

Maior que:

```javascript
db.livros.find({ ano: { $gt: 1900 } })
```

Maior ou igual:

```javascript
db.livros.find({ ano: { $gte: 1930 } })
```

Menor que:

```javascript
db.livros.find({ ano: { $lt: 1950 } })
```

Valores dentro de uma lista:

```javascript
db.livros.find({
  autor: { $in: ["Machado de Assis", "Clarice Lispector"] }
})
```

### Exercício

Na coleção `produtos`, consulte:

1. Produtos com preço maior que 100.
2. Produtos com estoque menor que 10.
3. Produtos de duas categorias escolhidas por você usando `$in`.

## 7. Operadores lógicos

Usando `$and`:

```javascript
db.livros.find({
  $and: [
    { disponivel: true },
    { ano: { $gt: 1900 } }
  ]
})
```

Usando `$or`:

```javascript
db.livros.find({
  $or: [
    { autor: "Machado de Assis" },
    { autor: "Clarice Lispector" }
  ]
})
```

Combinando condições de forma direta:

```javascript
db.livros.find({
  disponivel: true,
  ano: { $gt: 1900 }
})
```

### Exercício

Na coleção `produtos`, consulte:

1. Produtos ativos com estoque maior que zero.

## 8. Consultando arrays

Buscar livros que tenham o gênero `romance`:

```javascript
db.livros.find({ generos: "romance" })
```

Buscar livros que tenham **todos** os gêneros informados (romance **E** realismo):

```javascript
db.livros.find({
  generos: { $all: ["romance", "realismo"] }
})
```

Buscar livros que tenham **pelo menos um** dos gêneros informados (romance **OU** realismo):

```javascript
db.livros.find({
  generos: { $in: ["romance", "realismo"] }
})
```

Buscar livros que **não tenham nenhum** dos gêneros informados:

```javascript
db.livros.find({
  generos: { $nin: ["romance", "realismo"] }
})
```

Resumo dos operadores:

| Operador | Lógica | Exemplo de `generos` que casa |
|---|---|---|
| `$all` | contém **todos** | `["romance", "realismo", "drama"]` |
| `$in` | contém **pelo menos um** | `["romance"]`, `["realismo", "drama"]` |
| `$nin` | **não contém nenhum** | `["fantasia", "terror"]` |

## 9. Consultas por padrão de texto (equivalente ao `LIKE`)

No MongoDB, o equivalente ao `LIKE` do SQL é a **expressão regular**, que pode ser escrita com barras (`/.../`) ou com o operador `$regex`.

Buscar livros cujo título contenha `casmurro`:

```javascript
db.livros.find({ titulo: /casmurro/ })
```

A mesma consulta usando o operador explícito:

```javascript
db.livros.find({ titulo: { $regex: "casmurro" } })
```

Equivalências com o `LIKE`:

| MySQL | MongoDB | Significado |
|---|---|---|
| `LIKE '%dom%'` | `/dom/` | contém |
| `LIKE 'dom%'` | `/^dom/` | começa com |
| `LIKE '%dom'` | `/dom$/` | termina com |
| `LIKE 'dom'` | `/^dom$/` | igual exato |
| `LIKE 'd_m'` | `/^d.m$/` | `_` vira `.` (um caractere qualquer) |
| `NOT LIKE '%dom%'` | `{ $not: /dom/ }` | não contém |

### Ignorando maiúsculas e minúsculas

Por padrão, a expressão regular diferencia maiúsculas de minúsculas. Para ignorar essa diferença, use a opção `i`:

```javascript
db.livros.find({ titulo: /dom casmurro/i })
```

Ou, com o operador explícito:

```javascript
db.livros.find({ titulo: { $regex: "dom casmurro", $options: "i" } })
```

### Usando padrões dentro de arrays

A expressão regular também funciona em campos do tipo array. Buscar livros que tenham algum gênero começando com `rom`:

```javascript
db.livros.find({ generos: /^rom/i })
```

> **Atenção:** a expressão regular não ignora acentos. A consulta `/romance/` não encontra `Románce`.

## 10. Ordenação e limite

Ordenar por ano crescente:

```javascript
db.livros.find().sort({ ano: 1 })
```

Ordenar por ano decrescente:

```javascript
db.livros.find().sort({ ano: -1 })
```

Limitar a quantidade de resultados:

```javascript
db.livros.find().limit(2)
```

Ordenar e limitar:

```javascript
db.livros.find().sort({ ano: -1 }).limit(2)
```

## 11. Atualizando documentos

Atualizar um documento:

```javascript
db.livros.updateOne(
  { titulo: "Capitaes da Areia" },
  { $set: { disponivel: true } }
)
```

Atualizar vários documentos:

```javascript
db.livros.updateMany(
  { autor: "Machado de Assis" },
  { $set: { nacionalidadeAutor: "brasileira" } }
)
```

Incrementar um valor numérico:

```javascript
db.produtos.updateOne(
  { nome: "Teclado" },
  { $inc: { estoque: 5 } }
)
```

Adicionar item em array:

```javascript
db.livros.updateOne(
  { titulo: "Dom Casmurro" },
  { $push: { generos: "literatura brasileira" } }
)
```

Remover item de array:

```javascript
db.livros.updateOne(
  { titulo: "Dom Casmurro" },
  { $pull: { generos: "literatura brasileira" } }
)
```

### Exercício

## 12. Removendo documentos

Remover um documento:

```javascript

```

Remover vários documentos:

```javascript
db.livros.deleteMany({ disponivel: false })
```

Remover todos os documentos de uma coleção:


Apagar uma coleção inteira:

```javascript
db.livros.drop()
```

## 14. Agregação inicial

Agrupar livros por autor:

```javascript
db.livros.aggregate([
  {
    $group: {
      _id: "$autor",
      total: { $sum: 1 }
    }
  }
])
```

Filtrar antes de agrupar:

```javascript
db.livros.aggregate([
  { $match: { disponivel: true } },
  {
    $group: {
      _id: "$autor",
      totalDisponiveis: { $sum: 1 }
    }
  }
])
```

Calcular média:

```javascript
db.produtos.aggregate([
  {
    $group: {
      _id: "$categoria",
      precoMedio: { $avg: "$preco" },
      totalProdutos: { $sum: 1 }
    }
  }
])
```

Ordenar resultado de agregação:

```javascript
db.produtos.aggregate([
  {
    $group: {
      _id: "$categoria",
      estoqueTotal: { $sum: "$estoque" }
    }
  },
  { $sort: { estoqueTotal: -1 } }
])
```

### Exercício

Na coleção `produtos`, crie agregações para responder:

1. Quantos produtos existem por categoria?
2. Qual o preço médio por categoria?
3. Qual categoria possui maior estoque total?
